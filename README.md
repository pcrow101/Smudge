# Smudge 

Smudge is a Markdown editor with a live preview.  Formatting is rendered directly in the editor as you type, while the raw Markdown source stays fully editable. Switch between Preview and Raw mode at any time with the toolbar picker or ⇧⌘P — clicking or moving the cursor into any formatted element always reveals its raw source for editing.

Documents can be export as HTML or PDF if a standalone rendered copy is required.
